# Projetos Claude Code

Repositório de estudos e projetos desenvolvidos com o auxílio do **Claude Code**, a ferramenta de linha de comando da Anthropic para desenvolvimento assistido por IA.

## Sobre

Este repositório reúne experimentos, exercícios e projetos criados durante os estudos de 2026, explorando como usar o Claude Code no dia a dia do desenvolvimento de software.

## Estrutura

```
ProjetoX/
└── README.md
```

> A estrutura será atualizada conforme novos projetos forem adicionados.

## Como usar

1. Clone o repositório:
   ```bash
   git clone https://github.com/DiegoGoisDev/Projetos-Claude-Code.git
   ```
2. Acesse a pasta do projeto:
   ```bash
   cd Projetos-Claude-Code
   ```
